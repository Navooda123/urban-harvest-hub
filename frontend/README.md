# Urban Harvest Hub — Frontend

React + Vite SPA/PWA frontend for the Urban Harvest Hub platform.

## Setup

```bash
npm install
npm run dev       # Development server → http://localhost:5173
npm run build     # Production build
npm run preview   # Preview production build locally
```

## Environment Variables

Create a `.env` file (already included):

```env
VITE_API_URL=http://localhost:5000
VITE_OPENWEATHER_API_KEY=   # Optional: OpenWeatherMap API key
```

See the [root README](../README.md) for full setup and testing documentation.
